# Demo script (2–3 minutes)

1. Open the app. Sign in as `hr@acme.test` / `Password123!`.
2. Search the 10k directory (name or email). Filter by country.
3. Open a row, change annual salary, save. Show last editor.
4. Open Pay insights: headcount, payroll **by currency**, USD disclaimer, pay-band chart.
5. Export CSV of the current filter.
6. Sign out. Sign in as `finance@acme.test`. Directory still works; salary save and export are hidden.
7. Optionally sign in as `admin@acme.test` and add an employee.

If recording: keep the Excel pain in one sentence at the start — “this used to be a spreadsheet.”
